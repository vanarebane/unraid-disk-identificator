**Disk Identificator**

Turns on the identification (locate) LED of a drive bay on LSI/Avago/Broadcom SAS3 and SAS2 HBAs using `sas3ircu` / `sas2ircu` (bundled).
Adds an ID button to the Dashboard and Main disk tables, with per-enclosure LED colour and slot to LED remapping
in Settings > User Utilities > Disk Identificator.
